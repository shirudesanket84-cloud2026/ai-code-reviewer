# AI-Powered Code Reviewer & Security Scanner

A lightweight and efficient Python-based Command Line Interface (CLI) tool designed to help developers automatically scan their source code for potential security risks, hardcoded secrets, and vulnerabilities.

## Features
- Scans Python files recursively within directories.
- Detects hardcoded secrets, passwords, API keys, and access tokens.
- Excludes self-referencing scripts to prevent false positives.
- Simple, fast, and 100% open-source.
